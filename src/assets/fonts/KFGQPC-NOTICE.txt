Note on the Hafs version
------------------------
The app previously bundled UthmanicHafs1 Ver09 (a 2011 build). It now uses the
Complex's current v0.18 (2019). Verified before the swap:

  vertical metrics   identical (hhea 2400/-1200, OS/2 typo 2400/-1200,
                     winAsc/Desc 2400/1200, upem 2048) — so line layout,
                     and with it the recitation cue geometry, cannot shift
  cmap               strict superset: 0 codepoints lost, 337 gained
  glyphs             1071 -> 1412

Word-level recitation sync is unaffected by construction: segmentation is
`text.split(/\s+/)` over the Unicode text, which no font can influence.

Do NOT substitute the Complex's "Hafs smart" face (v8). Despite the name it is
not Unicode-encoded — its cmap is 2754 private-use entries with no alef, beh or
harakat — and it would render the mushaf as empty boxes.
