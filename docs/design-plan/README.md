Generated by a 25-agent workflow on 2026-07-27. Every spec below was written
against the measured Phase 0 audit, then independently attacked by three
auditors — manhaj, performance/feasibility, and accessibility/RTL.

**These specifications are not approved and are not implementation-ready.**
281 findings were raised against them, 66 of them blocking. The findings live
in `findings.md` and each one names the spec section it invalidates. Read the
findings before implementing any section.
